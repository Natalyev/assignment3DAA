# Подготовка к защите: Maze Escape

ID 252119, Nataliyev Daniyar, SE-2536.

## Что делает проект

Клетки — вершины, стены между соседними клетками — потенциальные рёбра.
DSU помогает убирать стены, не создавая циклов. Получается дерево.
DFS находит единственный простой путь к выходу.
Отдельный ориентированный граф slides описывает односторонние переходы.
Kosaraju объединяет взаимно достижимые клетки в зоны, а проход по DAG зон
находит длиннейшую цепочку и самый дешёвый маршрут.

## Что объяснить в каждом классе

- `DisjointSet`: `parent` хранит родителей, `size` — размеры множеств у корней,
  `groups` — число компонент. `find` сначала находит корень, затем сжимает путь.
  `union` соединяет только разные корни и присоединяет меньшее дерево к большему.
- `Maze.breakWalls`: рассматривает стены в порядке файла и принимает только
  успешные объединения. Каждое объединение уменьшает число компонент на один.
- `Maze.cheapestMaze`: сначала сортирует индексы стен по стоимости, затем
  делает те же проверки через DSU. Это Kruskal.
- `Maze.primCost`: начинает с клетки 0, хранит доступные рёбра в PriorityQueue.
  Старое ребро, у которого оба конца уже посещены, пропускается.
- `Escape`: массив `stack` хранит текущий путь DFS, `direction` — следующую
  проверяемую сторону каждого кадра. При возврате удаляется вершина стека.
  `visited` запрещает повторное посещение. Счётчик увеличивается при входе в клетку.
- `Zones.kosaraju`: первый проход записывает вершину только после обработки
  всех исходящих рёбер. Второй идёт в обратном порядке завершения по обратным
  рёбрам. Каждый запуск второго DFS получает новый номер зоны.
- `Zones.routes`: внутренние рёбра зон игнорируются, параллельные заменяются
  самым дешёвым. Номера зон топологические, поэтому одного прохода достаточно.

## Типичные вопросы

**Почему убрано n-1 стен?** Было n компонент, осталось 1; каждое успешное
объединение уменьшает их число на один.

**Почему путь единственный?** Получено дерево: связный граф без циклов.
Два различных простых пути создали бы цикл.

**Почему первая миссия не гарантирует минимальную цену?** Она использует
порядок файла. Kruskal в миссии 2 использует порядок стоимости.

**Почему DSU быстрый?** Union by size ограничивает высоту дерева,
path compression сокращает повторные поиски. Амортизированно O(alpha(n)).

**Почему DFS не переполнит стек Java?** Нет рекурсивных вызовов:
стек обхода хранится в массивах в куче памяти.

**Что такое SCC?** Максимальное множество вершин, в котором из любой вершины
можно добраться до любой другой по направленным рёбрам.

**Почему нельзя считать порядок первого обнаружения finish order?**
Finish order записывает вершину после всех её потомков; именно этот порядок
используется в доказательстве Kosaraju.

**Почему DAG, если зон столько же, сколько клеток?** Здесь нет петель.
Любой цикл из двух или более клеток образовал бы SCC размером больше одного.

**Зачем проверять недостижимое расстояние перед сложением?**
Long.MAX_VALUE обозначает бесконечность; прибавление к нему может переполниться.

**Почему не Dijkstra?** Зоны уже топологически упорядочены. Все предшественники
обработаны раньше вершины, поэтому достаточно релаксаций за O(z+e).
