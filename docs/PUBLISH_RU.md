# Публикация и сдача

Проект готов локально, но сдача требует публичного репозитория GitHub
и ссылки в Moodle. ZIP не заменяет ссылку.

1. Войди в GitHub и создай пустой публичный репозиторий, например
   `maze-escape`. Не добавляй README или другие файлы при создании:
   они уже есть в локальном проекте.
2. Открой PowerShell в папке `maze-escape`.
3. Подставь настоящий URL своего репозитория и выполни:

```powershell
git remote add origin https://github.com/YOUR_USERNAME/maze-escape.git
git push -u origin main
```

Если Git попросит вход, пройди авторизацию. Не передавай пароль или токен в чат.
Если origin уже настроен, сначала проверь `git remote -v`.

4. Проверь на GitHub ветку main, README, data/walls.txt, data/slides.txt,
   output/maze.png и историю коммитов.
5. Проверь, что ссылка доступна без входа, и вставь её в Moodle до дедлайна.

Публикуй существующий локальный Git-репозиторий, чтобы сохранить этапы работы.
Обычный ZIP исходников не содержит коммиты. Резервная копия истории сохранена
рядом с проектом в `maze-escape-252119.bundle`; при потере папки её можно
восстановить в новую папку:

```powershell
git clone maze-escape-252119.bundle maze-escape-restored
```

Перед сдачей прочитай и адаптируй код и README в соответствии с правилами
использования AI. Раздел AI use уже описывает фактическую помощь Codex.
